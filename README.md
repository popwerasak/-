# แปลผล InBody

เว็บแอพช่วยแปลผลการวัดองค์ประกอบร่างกาย (InBody / ACCUNIQ BC380) เป็นภาษาไทย

- **สแกน QR บนใบผล ACCUNIQ** (อัปโหลดรูปใบผล หรือวางลิงก์ `QR.ACCUNIQ.COM/...`) แล้วระบบกรอกตัวเลขให้อัตโนมัติ
- หรือกรอกตัวเลขจากใบผลเอง → กด **แปลผล**
- ประเมิน BMI (เกณฑ์คนเอเชีย), % ไขมัน, ไขมันช่องท้อง, รอบเอว, ภาวะบวมน้ำ, กล้ามเนื้อแยกส่วน
- ดูแนวโน้มจากประวัติการวัด
- คู่มือสุขภาพตามผลของแต่ละคน (ลด BMI, อาหาร 2:1:1, หวาน มัน เค็ม 6:6:1, โปรตีน, แคลเซียม, ออกกำลังกาย, ท่าออกกำลังกายพร้อมภาพ เซต ครั้ง และเวลา, ตัวอย่างเมนู) อ้างอิงกรมอนามัย กระทรวงสาธารณสุข
- ข้อมูลเก็บในเบราว์เซอร์ของผู้ใช้เท่านั้น (localStorage)

## เปิดใช้งานผ่าน GitHub Pages

1. ไปที่ **Settings → Pages**
2. Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
3. รอสักครู่ เว็บจะอยู่ที่ `https://<username>.github.io/<repo>/`

ไม่ต้อง build — มีแค่ `index.html` และ `js/accuniq.js` (ตัวถอดรหัสข้อมูล QR)

> ใช้เพื่อความเข้าใจทั่วไปเท่านั้น ไม่ใช่การวินิจฉัยทางการแพทย์

# 🎗️ เกมควิซ "รู้ทันมะเร็งเต้านม" (แนว Kahoot)

อยู่ในโฟลเดอร์ `quiz/` เมื่อเปิด GitHub Pages แล้ว:

- **หน้าครู (เปิดบนโปรเจกเตอร์):** `https://<username>.github.io/<repo>/quiz/host.html`
- **หน้านักเรียน:** `https://<username>.github.io/<repo>/quiz/` (หรือสแกน QR บนจอครู)

วิธีเล่น
1. ครูเปิดหน้าครู → เลือกเวลาต่อข้อ → กด **สร้างห้องเกม** → ได้ PIN 4 หลัก และ QR Code
2. นักเรียนสแกน QR (PIN กรอกให้อัตโนมัติ) หรือเข้าเว็บแล้วพิมพ์ PIN → ตั้งชื่อเล่น เลือก Avatar เลือกคำนำหน้านาม (นาย / นาง / นางสาว / ดร. / อื่น ๆ) และกรอกชื่อ-นามสกุลสำหรับเกียรติบัตร (ระบบบังคับกรอกทั้งชื่อและนามสกุล, ชื่อจริงไม่แสดงบนจอ)
3. ครูกด **เริ่มเกม** → ตอบ "ถูกต้อง / ไม่ถูกต้อง" บนมือถือ ตอบถูกเร็วได้คะแนนมาก ตอบถูกติดกันได้โบนัส 🔥
4. จบเกมแสดงแท่นรางวัล 3 อันดับ → ปุ่ม 📋 ดูผลพร้อมชื่อจริง เรียงตามคะแนนหรือความเร็ว และ **ดาวน์โหลด CSV** (เปิดด้วย Excel ได้)

รายละเอียด
- แก้คำถาม / เฉลย / คำอธิบายได้ที่ `quiz/questions.js`
- ดนตรีประกอบและเสียงเอฟเฟกต์สร้างด้วย Web Audio ในเบราว์เซอร์ (ไม่ใช้ไฟล์เพลง) ปิดเสียงได้ที่ปุ่ม 🔊
- ไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง: รับส่งข้อมูลแบบเรียลไทม์ผ่าน MQTT public broker (EMQX, HiveMQ, Mosquitto พร้อมกันหลายตัว) โดยข้อความทุกชิ้นเข้ารหัส AES-GCM ด้วยกุญแจที่สร้างจาก PIN
- ถ้านักเรียนเผลอปิดหน้าเว็บ เปิดใหม่ได้ระบบจำผู้เล่นเดิม / ถ้าหน้าครูรีเฟรช กด **เล่นต่อห้องเดิม** ได้
- ใช้ broker ของตัวเองได้โดยเติม `?broker=wss://host:port/mqtt` ที่ลิงก์หน้าครู
