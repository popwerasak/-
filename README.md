# Local Object Remover (ออฟไลน์)

โปรแกรม Desktop สำหรับ Windows: **ระบายทับอะไรก็ได้ในภาพ → โปรแกรมลบแล้วเติมสิ่งที่ควรอยู่ตรงนั้น**
(สร้อยคอ → ผิวคอ, นาฬิกา → ข้อมือเปล่า, รองเท้า → เท้าเปล่า, หรือลบวัตถุอื่น ๆ) ภาพไม่ออกนอกเครื่อง

ออกแบบให้ใช้กับโน้ตบุ๊กที่ไม่มีการ์ดจอแยก (เช่น Ryzen 5 7535U + RAM 16 GB)

## วิธีใช้
1. เปิดภาพ (Ctrl+O) → **คลิกซ้ายระบาย** ทับสิ่งที่ต้องการลบ ให้เกินขอบนิดหน่อย (รวมเงา) / คลิกขวา = ลบรอยระบาย
2. เลือก **โหมด**
   - **เร็ว (ไม่ใช้ AI):** ได้ผลในไม่กี่วินาที เหมาะกับของเล็ก/บาง เช่น สายสร้อย ข้อความ รอยเปื้อน บนพื้นผิวเรียบ ไม่ต้องดาวน์โหลดโมเดล
   - **AI:** เติมได้เนียนกว่า เหมาะกับพื้นที่ใหญ่ (นาฬิกา รองเท้า) แต่บนเครื่องนี้ต้องรอหลายนาทีต่อภาพ
3. เลือก "งาน" (หรือปล่อย "ลบอัตโนมัติ") → กด **ลบ / เติมภาพ** → Ctrl+S บันทึก
4. ผลไม่ถูกใจ: กด Ctrl+Z กลับภาพต้นฉบับ แล้วลองใหม่ / เปลี่ยน Seed / เพิ่มจำนวนตัวเลือก

โปรแกรมครอปเฉพาะบริเวณรอบรอยระบาย ประมวลผล แล้ววางกลับ พิกเซลส่วนอื่นของภาพจึงคงเดิม 100%

## ติดตั้ง (Windows)
ต้องมี Python 3.10–3.12 (แนะนำ 3.12; **ไม่แนะนำ 3.13+** เพราะไลบรารีอาจยังไม่รองรับ) ติ๊ก "Add python.exe to PATH" ตอนติดตั้ง แล้วดับเบิลคลิก **`run.bat`** — มี Python หลายเวอร์ชันได้ สคริปต์จะเลือก 3.12/3.11/3.10 เอง
ครั้งแรกจะสร้าง `.venv` และติดตั้ง PyTorch (CPU) กับไลบรารีให้เอง แล้วเปิดโปรแกรม

โหมดเร็วใช้งานได้ทันทีหลังติดตั้ง

## เปิดโหมด AI (ดาวน์โหลดโมเดลครั้งเดียว)
```bash
.venv\Scripts\activate
python tools/download_model.py
```
จะได้โฟลเดอร์ `models/sd15-inpaint` (SD 1.5 Inpainting ขนาดราว 2–4 GB ขึ้นกับไฟล์ที่ repo มี) โปรแกรมจะหาเจอเอง
หลังจากนั้นปิดอินเทอร์เน็ตแล้วใช้ได้ (ช่อง "ออฟไลน์เต็มรูปแบบ" ติ๊กไว้ตั้งแต่แรก)

เคล็ดลับให้เร็วขึ้นบนเครื่องไม่มีการ์ดจอ: ความละเอียด AI 384–448, Steps 15–20, ตัวเลือก 1 ภาพ, ระบายพื้นที่ให้เล็กที่สุด, ปิดโปรแกรมอื่นที่กิน RAM
ถ้าต้องการลองใช้ GPU onboard ผ่าน DirectML: `pip install torch-directml` (ทดลอง อาจไม่เสถียร — ถ้ามีปัญหาให้ถอนออก)

## สถานะ (ตามจริง)
- ผ่านการทดสอบอัตโนมัติ (รวมหน้าต่างโปรแกรมแบบไม่มีจอ): ส่วนประมวลผลภาพ, **การระบาย mask**, **โหมดเร็ว** ตั้งแต่ระบายจนได้ผลลัพธ์และย้อนกลับ
- **ยังไม่เคยรันจริง:** โหมด AI (ไม่มีโมเดล/GPU ในสภาพแวดล้อมพัฒนา และเข้า Hugging Face ไม่ได้) และสคริปต์ดาวน์โหลดโมเดล — ถ้ามี error ส่งข้อความมาแก้ต่อได้
- โหมดเร็วใช้กับพื้นที่ใหญ่/พื้นผิวซับซ้อนไม่ได้ผลดี (จะเห็นเป็นรอยเบลอ) ให้ใช้โหมด AI
- ไม่รองรับ SDXL/FLUX ในเวอร์ชันนี้ (หนักเกินไปสำหรับ iGPU)
