# ThaiRealtimeTranslate

แอป iOS (SwiftUI) ที่ฟังเสียงพูดภาษา **อังกฤษ / เกาหลี / ญี่ปุ่น** จากไมโครโฟน
(รวมถึงไมค์ของ AirPods 4 / AirPods Pro 2 ที่เชื่อมต่ออยู่) แล้วแปลเป็น
**ภาษาไทย** แบบต่อเนื่อง (ทีละประโยค) โดยทำงาน **ออฟไลน์ได้ทั้งหมด** หลังจาก
ดาวน์โหลดโมเดลของแต่ละภาษาครั้งแรก

ใช้เฉพาะ framework ของ Apple:

- **Speech** (`SFSpeechRecognizer`, `requiresOnDeviceRecognition = true`) — แปลงเสียงเป็นข้อความบนเครื่อง
- **Translation** (`TranslationSession`, iOS 17.4+) — แปลข้อความบนเครื่อง

ไม่มีการส่งเสียงหรือข้อความออกไปเซิร์ฟเวอร์ภายนอกใด ๆ

## วิธีทำงานคร่าว ๆ

1. `AudioInputManager` แสดงรายชื่อไมโครโฟนที่ใช้ได้ (ไมค์เครื่อง / AirPods) ให้เลือก หรือปล่อยเป็น "อัตโนมัติ" เพื่อให้ iOS สลับไปใช้ AirPods เองเมื่อเชื่อมต่ออยู่
2. `SpeechRecognizer` เปิดไมค์ต่อเนื่อง รู้จำเสียงเป็นข้อความทีละประโยค (เมื่อเงียบไปสักพัก ถือว่าจบประโยค) แล้วเริ่มฟังประโยคถัดไปทันที
3. แต่ละประโยคที่จบแล้วจะถูกส่งเข้า `LiveTranslator` ซึ่งรันอยู่ใน `.translationTask` ของ SwiftUI เพื่อแปลเป็นไทยแบบสตรีม
4. หน้าจอ `ContentView` แสดงข้อความต้นฉบับที่กำลังพูด (จาง ๆ) และประวัติคำแปลภาษาไทย (ตัวใหญ่) เรียงจากบนลงล่าง

หมายเหตุ: แปลทีละ "ประโยค/ช่วงที่พูดจบ" ไม่ใช่ทีละคำ เพราะการแปลต้องอาศัย
บริบททั้งประโยคถึงจะแม่นยำ — เป็นวิธีเดียวกับโหมดสนทนาของแอปแปลภาษาทั่วไป
ดีเลย์ที่เกิดขึ้นจะประมาณเสี้ยววินาทีถึง 1-2 วินาทีหลังหยุดพูด ไม่ใช่หน่วง
เป็นนาที

## สิ่งที่ต้องมีก่อน build

- เครื่อง **Mac** ที่ลง **Xcode 15.4 ขึ้นไป** (แนะนำ Xcode 16 บน macOS ใหม่ล่าสุด)
- iPhone ที่ใช้ **iOS 17.4 ขึ้นไป**
- ติดตั้ง [XcodeGen](https://github.com/yonaskolb/XcodeGen) (ใช้สร้างไฟล์ `.xcodeproj` จาก `project.yml` เพราะไฟล์โปรเจกต์ของ Xcode ไม่เหมาะจะสร้าง/แก้ด้วยมือ):

  ```bash
  brew install xcodegen
  ```

## วิธี build และติดตั้งลงเครื่อง

```bash
cd ThaiRealtimeTranslate
xcodegen generate
open ThaiRealtimeTranslate.xcodeproj
```

ใน Xcode:

1. เลือก target `ThaiRealtimeTranslate` → แท็บ **Signing & Capabilities**
2. ใส่ Apple ID ของคุณเป็น **Team** (ใช้บัญชีฟรีได้ ไม่ต้องเสียเงิน แต่แอปจะใช้งานได้ 7 วันแล้วต้อง build ซ้ำผ่าน Xcode อีกครั้ง — ถ้าอยากติดตั้งได้นานขึ้นโดยไม่ต้องต่อ Mac บ่อย ๆ ต้องสมัคร Apple Developer Program ปีละ $99)
3. เสียบ iPhone เข้ากับ Mac (หรือเชื่อมผ่าน Wi-Fi หลัง pair ครั้งแรก) เลือกเป็น run destination
4. กด Run (▶) — ครั้งแรกในเครื่องต้องไปที่ **Settings > General > VPN & Device Management** บน iPhone เพื่อ "ไว้ใจ" นักพัฒนา (Apple ID ของคุณ) ก่อนเปิดแอปได้

## การตั้งค่าครั้งแรกให้ทำงานออฟไลน์ได้จริง

- **โมเดลรู้จำเสียง**: iOS จะดาวน์โหลดโมเดลรู้จำเสียงแบบออฟไลน์ของแต่ละภาษาให้อัตโนมัติตอนใช้งานครั้งแรก (ต้องมีอินเทอร์เน็ตตอนนั้น) จากนั้นจะ cache ไว้ในเครื่องและใช้ออฟไลน์ได้เลย — แนะนำให้เปิดแอปและลองพูดแต่ละภาษา (อังกฤษ/เกาหลี/ญี่ปุ่น) สักครั้งตอนต่อ Wi-Fi ก่อนพกไปใช้แบบไม่มีเน็ต
- **โมเดลแปลภาษา**: ครั้งแรกที่กดเริ่มฟัง แอปจะเรียก `prepareTranslation()` ซึ่ง iOS จะเด้งหน้าต่างให้ดาวน์โหลดแพ็กภาษา (คู่ ภาษาต้นทาง → ไทย) ให้กดดาวน์โหลดตอนมีอินเทอร์เน็ต หรือจะเข้าไปโหลดล่วงหน้าเองก็ได้ที่ **Settings > Apps > Translate > Downloaded Languages** เลือกดาวน์โหลด อังกฤษ, เกาหลี, ญี่ปุ่น และ ไทย ให้ครบ

หลังจากดาวน์โหลดครบแล้ว **เปิดโหมดเครื่องบินทดสอบได้เลย แอปจะยังฟังและแปลได้ตามปกติ**

## การใช้กับ AirPods

ไม่ต้องตั้งค่าอะไรเพิ่มในโค้ด — AirPods (ทั้ง 4 และ Pro 2) เป็นไมโครโฟนบลูทูธมาตรฐาน
(HFP) เมื่อ pair และสวมอยู่ iOS จะเสนอเป็นตัวเลือกไมค์ในแอปโดยอัตโนมัติ
(หรือเลือก "อัตโนมัติ" ในตัวเลือกไมโครโฟนของแอปเพื่อให้ iOS สลับให้เอง)

## ข้อจำกัดที่ควรรู้

- ไมค์บลูทูธ (AirPods) ส่งเสียงด้วยอัตราบิตต่ำกว่าที่ไมค์บนตัวเครื่อง เหมาะกับเสียงพูดอยู่แล้ว คุณภาพเพียงพอสำหรับรู้จำเสียง แต่ในที่เสียงดังมากอาจแปลผิดได้
- นี่เป็นแอปสำหรับติดตั้งใช้เองในเครื่องคุณ (ไม่ได้ขึ้น App Store) — ถ้าอยากแจกให้คนอื่นใช้ด้วยต้องสมัคร Apple Developer Program และแจกผ่าน TestFlight หรือ App Store
- API ของ `Translation` framework ค่อนข้างใหม่ (เปิดตัว iOS 17.4, ปรับปรุงต่อใน iOS 18) โค้ดนี้เขียนตามสเปกล่าสุดที่ทราบ แต่ยังไม่ได้ build ทดสอบจริงบน Xcode (สภาพแวดล้อมที่เขียนโค้ดนี้ไม่มี macOS/Xcode) — ถ้า Xcode ฟ้อง error เล็กน้อยเกี่ยวกับชื่อ method ของ `TranslationSession` ให้เช็คกับเอกสารล่าสุดใน Xcode (⌘-click ที่ `TranslationSession`) เพื่อแก้ชื่อให้ตรง SDK เวอร์ชันที่ใช้

## โครงสร้างโปรเจกต์

```
ThaiRealtimeTranslate/
├── project.yml                  # นิยามโปรเจกต์สำหรับ XcodeGen
└── Sources/
    ├── App/ThaiRealtimeTranslateApp.swift
    ├── Models/SourceLanguage.swift       # ภาษาที่เลือกได้ + mapping ไป locale
    ├── Audio/AudioInputManager.swift     # เลือก/ติดตามไมโครโฟน (รวม AirPods)
    ├── Speech/SpeechRecognizer.swift     # ฟังเสียงต่อเนื่อง + รู้จำเสียงออฟไลน์
    ├── Translation/LiveTranslator.swift  # แปลข้อความแบบสตรีมด้วย Translation framework
    └── Views/
        ├── ContentView.swift             # หน้าหลัก: เลือกภาษา, เลือกไมค์, ปุ่มเริ่ม/หยุด, ประวัติคำแปล
        └── TranslationHost.swift         # view เปล่าที่ใช้ผูก .translationTask
```
