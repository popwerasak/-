# EngPrax — ฝึกพูดภาษาอังกฤษกับ AI

เว็บแอปสำหรับฝึกพูดภาษาอังกฤษ: พูด (หรือพิมพ์) เป็นภาษาไทยว่าคุณอยากพูดอะไร
เช่น *"ฉันจะเปิดทีวี ช่วยพูดภาษาอังกฤษให้ฉันฟังหน่อย"* แอปจะแปลงเป็นประโยค
ภาษาอังกฤษที่เป็นธรรมชาติ แสดงเป็นตัวหนังสือ แล้วพูดให้ฟังทันที พร้อมปุ่ม
**ฟังซ้ำ** และปรับความเร็วการพูดได้ (ช้า/ปกติ/เร็ว) — เหมาะกับการฝึกฟังและพูด
ทุกวันเพื่อสื่อสารได้ภายใน 3 เดือน

## รันบน Windows เครื่องนี้ได้เลย

### สิ่งที่ต้องมี

- [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป (ดาวน์โหลดตัวติดตั้ง LTS แล้วกด Next ไปเรื่อย ๆ)
- เบราว์เซอร์ **Google Chrome** หรือ **Microsoft Edge** (จำเป็น — ใช้ฟีเจอร์ฟังเสียงพูดของเบราว์เซอร์ ซึ่ง Firefox/Safari รองรับไม่ดี)

### ขั้นตอน

เปิด PowerShell หรือ Command Prompt แล้วรัน:

```bash
cd english-speaking-coach
npm install
npm start
```

จะเห็นข้อความ `English speaking coach running at http://localhost:3000`
เปิด Chrome/Edge ไปที่ **http://localhost:3000** แล้วกดอนุญาตให้เว็บใช้ไมโครโฟนเมื่อเบราว์เซอร์ถาม

ครั้งต่อไปแค่เปิดโฟลเดอร์นี้แล้วรัน `npm start` อีกครั้งก็พอ (ไม่ต้อง `npm install` ซ้ำ)

## วิธีใช้

1. กดปุ่มไมค์ตรงกลาง แล้วพูดเป็นภาษาไทยว่าคุณอยากพูดอะไรเป็นภาษาอังกฤษ (หรือพิมพ์ในช่องข้อความก็ได้ถ้าไมค์มีปัญหา)
2. แอปจะแสดงข้อความไทยที่พูด แล้วแปลเป็นประโยคภาษาอังกฤษ พร้อมพูดให้ฟังทันที
3. กด **ฟังซ้ำ** เพื่อฟังอีกครั้ง ลองเปลี่ยนความเร็วเป็น "พูดช้า" ถ้ายังฟังไม่ทัน
4. ประโยคที่ฝึกไปแล้วจะถูกเก็บไว้ใน **ประวัติ** ด้านล่าง (เก็บในเบราว์เซอร์เครื่องนี้) กดที่รายการเก่าเพื่อฟังซ้ำได้ตลอด

## เครื่องมือแปลภาษาที่ใช้

ค่าเริ่มต้น (ไม่ต้องตั้งค่าอะไรเพิ่ม) แอปใช้บริการแปลภาษาฟรี **MyMemory** — เพียงพอ
สำหรับประโยคสนทนาทั่วไป แต่บางประโยคอาจแปลได้ไม่เป็นธรรมชาติเท่า AI

ถ้าอยากได้คำแปลที่เป็นธรรมชาติและตรงบริบทมากขึ้น (แนะนำสำหรับการฝึกจริงจัง)
ใส่ **Anthropic API key** ของคุณเองก่อนรัน `npm start`:

```powershell
# PowerShell
$env:ANTHROPIC_API_KEY = "sk-ant-..."
npm start
```

```cmd
:: Command Prompt
set ANTHROPIC_API_KEY=sk-ant-...
npm start
```

เมื่อใส่คีย์แล้ว มุมขวาบนของแอปจะขึ้นว่า "Powered by Claude" และคำแปลจะเป็น
ประโยคสนทนาธรรมชาติมากขึ้น (ไม่ใช่แปลตรงตัว) — สมัครขอคีย์ได้ที่
https://console.anthropic.com (มีค่าใช้จ่ายตามการใช้งานจริง เล็กน้อยมากสำหรับ
ประโยคสั้น ๆ แบบนี้)

## ข้อจำกัดที่ควรรู้

- การฟังเสียงพูดภาษาไทย (speech-to-text) ใช้ Web Speech API ของเบราว์เซอร์
  ซึ่ง **ต้องมีอินเทอร์เน็ต** ขณะใช้งาน (เบราว์เซอร์ส่งเสียงไปประมวลผลที่เซิร์ฟเวอร์
  ของ Google/Microsoft เบื้องหลัง) — ต่างจากโปรเจกต์ iPhone ออฟไลน์ก่อนหน้านี้
- การพูดภาษาอังกฤษ (text-to-speech) ใช้เสียงที่มีอยู่ในเครื่อง/เบราว์เซอร์อยู่แล้ว
  ทำงานได้แม้ไม่มีเน็ต แต่คุณภาพเสียงขึ้นอยู่กับเสียงที่ Windows ติดตั้งไว้
  (ถ้าอยากได้เสียงที่เป็นธรรมชาติกว่านี้ ไปที่ Windows Settings > Time & Language
  > Speech แล้วดาวน์โหลดเสียง "Natural" ภาษาอังกฤษเพิ่มได้)
- ประวัติเก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น (localStorage) ถ้าเปลี่ยนเบราว์เซอร์
  หรือล้างข้อมูลเว็บไซต์ ประวัติจะหายไป
