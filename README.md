# แปลผล InBody

เว็บแอพช่วยแปลผลการวัดองค์ประกอบร่างกาย (InBody / ACCUNIQ BC380) เป็นภาษาไทย

- กรอกตัวเลขจากใบผล → กด **แปลผล**
- ประเมิน BMI (เกณฑ์คนเอเชีย), % ไขมัน, ไขมันช่องท้อง, รอบเอว, ภาวะบวมน้ำ, กล้ามเนื้อแยกส่วน
- ดูแนวโน้มจากประวัติการวัด และคำแนะนำเรื่องพลังงาน โปรตีน และการออกกำลังกาย
- ข้อมูลเก็บในเบราว์เซอร์ของผู้ใช้เท่านั้น (localStorage)

## เปิดใช้งานผ่าน GitHub Pages

1. ไปที่ **Settings → Pages**
2. Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
3. รอสักครู่ เว็บจะอยู่ที่ `https://<username>.github.io/<repo>/`

ไม่ต้อง build — เป็นไฟล์ `index.html` ไฟล์เดียว

> ใช้เพื่อความเข้าใจทั่วไปเท่านั้น ไม่ใช่การวินิจฉัยทางการแพทย์
